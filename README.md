# 食品寄递协同监管

衔接食品经营资质核验、寄递交接和跨部门风险处置。

## 领域资料

`contracts/domain.schema.json` 记录共享资料结构，`fixtures/domain.json` 是不含真实个人信息的示例。参与方包括快递员、食品协议客户、邮政管理人员、市场监管人员。

当前资料依据以下业务事实维护：

- 湖南建立市场监管与邮政管理的信息互通和线索互移机制
- 首次揽件可核验经营许可及实际揽件场地
- 快递员可作为监督员上报违法和储运风险
- 经营资质登记场所可能与实际外设仓库不一致
- 扫码重试只形成一次核验，同一核验码内容改变立即隔离
- 邮政部门先确认寄递事实，市场监管部门再决定受理、移交、合并调查或解除
- 包裹获准进入寄递网络前必须确认当前证据上没有生效风险

监管服务需满足的约束包括：保存客户资质快照、核验码、登记场所与外设仓库；记录揽件批次、实名验视安检结果、温控要求及运输交接；两部门仅读取职责所需字段，举报人身份另行保护；线索冻结后补充材料只追加版本；退回补正与跨辖区移交携带原期限及交接回执，部门切换不重新计时；沿包裹编号可查资质核验、现场发现、部门去向和处置结论，未通过食品标明滞留缺口。

## 开发命令

- 运行测试：`npm test`
- 编译或构建：`npm run build`

上述命令只读取仓库内文件，不连接外部业务服务。
